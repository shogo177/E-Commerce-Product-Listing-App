# 🛒 Cyberpunk Product Listing App

A stylish, cyberpunk-themed React app for browsing and filtering tech products by category.

## Features

- ⚡ Cyberpunk-inspired neon UI
- 🗂️ Filter products by category
- 📦 Product cards with name, price, description, and category
- 💅 Custom responsive CSS styling

## Project Structure

```
src/
  App.jsx
  App.css
  components/
    ProductList.jsx
    ProductItem.jsx
```

- **App.jsx**: Main app logic, state, and category filtering
- **App.css**: Cyberpunk styles
- **components/ProductList.jsx**: Renders the list of products
- **components/ProductItem.jsx**:Renders a single product card
